Use full desktop AI coding environments (**Google Antigravity**, **Cursor**, **Claude Desktop**) to author, debug, and inspect Bhai Codes on your Android device over Wi-Fi via Model Context Protocol (MCP).

  • Zero repo access needed for external contributors (Download mcp_proxy.py directly from phone).
  • Real-time Server-Sent Events (SSE) auto-switch desktop dashboard tabs via phone voice.
  • Full access to mcp_list_agents, mcp_read_agent, and mcp_deploy_agent.

4-Tier Security & Due Diligence

Every generated script passes through strict automated policy and permission gates.

Class Designation Execution Privileges & Boundary
Class 1 CORE Native Dart shell, hardware sensors, secure keystore storage.
Class 2 VERIFIED (Mere Bhai) Passed 7-point due diligence audit; ambient voice listening enabled; background execution.
Class 3 DUE DILIGENCE Restricted to explicit delegated scoping ("Ask [Agent] to..."); deaf to general voice activity.
Class 4 SANDBOX (Sabke Bhai) Quarantined test zone; zero sensor access; executes strictly in-memory or on simulated replays.
