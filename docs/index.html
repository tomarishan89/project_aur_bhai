📖 OVERVIEW

In Short...

Project Aur Bhai is an open-source Flutter app that allows you to use voice commands to generate, test, and run sandboxed JavaScript tools (called Bhai Codes) directly on your phone.

🛡️ 100% Privacy (Sovereignty)

Uses a Bring-Your-Own-Key (BYOK) model for LLMs. All data, telemetry, and voice recordings remain encrypted locally in an SQLite vault.

🧠 On-Device Sandbox

Tools are run locally using an embedded QuickJS engine with a 7-point security check to prevent malicious network access or data leaks.

🌐 Local Edge Server

Runs a background HTTP server so you can view real-time HTML5 dashboards and live charts on your desktop browser over your local Wi-Fi.

💻 Desktop IDE Bridge

Connect desktop AI tools directly to your phone using the Model Context Protocol (MCP) to write, debug, and hot-reload code.

It comes pre-packaged with several seed tools out of the box, including an expense tracker (Accountant), a sensor visualization tool (Telemeter), a pure JavaScript Calculator, a voice-dictated Note Taker, and an offline roadmap triage pipeline (I Wish).

🧩 UNDERSTANDING BHAI CODES

What is a Bhai Code?

A Bhai Code is a sandboxed JavaScript tool — generated by AI from a voice prompt, tested via an automated 7-point security audit, and executed locally on your phone's CPU inside the QuickJS runtime.

⚡ Mere Bhai — Your Verified Vault

All tools that pass the 7-point due diligence audit live in Mere Bhai (My Bhai) — your personal installed agent vault. Each is C2 Verified, meaning it has full ambient voice listening and background execution privileges.

  • One-tap execute, inspect source code, or export as portable .bundle.json
  • Share via AirDrop, Bluetooth, WhatsApp, or email
  • Root creators retain permanent attribution across multi-hop remixes

👥 Sabke Bhai — Community Catalog

Discover community-authored tools in Sabke Bhai (Everyone's Bhai). Sync via your GitHub Personal Access Token (PAT) — browse, preview, and fork tools from your friend circle directly on-device.

  • Decentralized distribution — no central app store gatekeeping
  • Immutable lineage chain: @core → @alice → @bob → @you
  • File issue reports directly from the device to the friend repository

🛡️ Sandbox & Due Diligence Gate

Every untrusted tool enters a Class 4 Quarantined Sandbox — zero sensor access, in-memory execution only. It must pass the automated 7-point policy audit before promotion.

C1 · CORE Native Dart shell, hardware sensors, secure keystore
C2 · VERIFIED Passed audit; ambient voice & background execution
C3 · DUE DILIGENCE Restricted delegated scoping ("Ask [Agent] to…")
C4 · SANDBOX Quarantined test zone; zero sensor access; in-memory only

Author a Bhai Code

By App (Voice on Phone)

"Haan Bhai, build me a pomodoro timer with 25-minute work sessions and 5-minute breaks"
💻

By IDE (MCP Desktop Bridge)

Use Google Antigravity, Cursor, or Claude Desktop to author, debug, and hot-reload Bhai Codes on your phone over Wi-Fi via the Model Context Protocol (MCP). Zero repo access needed.

mcp_config.json 
{
  "mcpServers": {
    "aur-bhai-phone": {
      "command": "python",
      "args": [
        "tool/mcp_proxy.py",
        "--url", "http://192.168.1.50:8080/api/mcp",
        "--token", "8NSVBE"
      ]
    }
  }
}
