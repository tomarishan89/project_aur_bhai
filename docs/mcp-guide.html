🔌 MODEL CONTEXT PROTOCOL (MCP)

Remote Developer Guide

Author, refine, test, and hot-reload Bhai Code directly on your Android phone using desktop AI coding assistants over local Wi-Fi.

ZERO CLOUD PROXY · LOCAL WI-FI ONLY

1. Overview & Architecture

Instead of coding on a mobile touch keyboard, the MCP Bridge lets you use full desktop AI coding agents to write JavaScript and HTML5 dashboards that execute directly in your phone's secure QuickJS sandbox.

┌───────────────────────────┐ Wi-Fi (HTTP / JSON-RPC) ┌───────────────────────────────────┐ │ Desktop IDE │ ◄─────────────────────────► │ Aur Bhai Android Device │ │ (Antigravity / Cursor) │ │ (Local Shelf Server on Port 8080) │ │ │ │ └─────────────────┬─────────────────┘ │ stdio │ │ │ │ ▼ │ │ │ mcp_proxy.py │ ▼ │ (JSON-RPC stdio adapter) │ Sovereign Vault & QuickJS └───────────────────────────┘ (JS Agent Registry & SQLite)

The lightweight mcp_proxy.py script translates standard MCP stdio messages from your desktop IDE into authenticated HTTP JSON-RPC calls over your local Wi-Fi directly to your phone's Shelf server.

2. Setting Up Your Phone

Follow these 5 steps to expose your phone's MCP bridge to your local network:

  1. Ensure your phone and computer are connected to the same Wi-Fi network.
  2. Open Project Aur Bhai on your phone.
  3. Swipe right to the Settings tab and scroll down to Local Edge Server.
  4. Toggle Allow LAN access to ON.
  5. Note the details shown in the DEVELOPER MODE (MCP BRIDGE) card:
    • Server URL: http://<PHONE_IP>:8080/api/mcp
    • Pair Code: e.g. CGVX68

3. Configuring Your Desktop IDE

Select your desktop environment below and paste the configuration into your IDE's MCP settings file:

Add to ~/.gemini/config/mcp_config.json: 

{
  "mcpServers": {
    "aur-bhai-phone": {
      "command": "python",
      "args": [
        "path/to/tool/mcp_proxy.py",
        "--url", "http://<PHONE_IP>:8080/api/mcp",
        "--token", "<PAIR_TOKEN>"
      ]
    }
  }
}

4. Available MCP Tools

Once connected, your desktop AI agent has direct programmatic access to your phone via 5 tools:

Tool Name Purpose Sample Prompt
mcp_list_agents Lists all installed Bhai Codes and security verification tiers. "What agents are installed on my phone?"
mcp_read_agent Reads the active JavaScript code, schema, and vault assets. "Read the Accountant agent source code."
mcp_deploy_agent Deploys or updates an agent directly into the phone's Sovereign Vault. "Deploy this updated calculation script to my phone."
mcp_run_agent Executes the agent in the phone's QuickJS sandbox and returns logs. "Run Accountant with 250 spent on groceries."
mcp_query_telemetry Runs guarded read-only SQL queries on the SQLite vault. "Check the last 10 entries in the telemetry table."

5. How to Obtain `mcp_proxy.py`

The proxy script is a single-file Python script (50 lines) with zero external dependencies — it uses only the standard library (urllib and json).

  • From the Repository: Located at tool/mcp_proxy.py in the repository root.
  • From the Phone: When LAN access is enabled, download directly by visiting http://<PHONE_IP>:8080/tool/mcp_proxy.py in your desktop browser.
